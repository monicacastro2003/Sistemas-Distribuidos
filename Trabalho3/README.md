# Trabalho 3 - Supermercado API REST

**Sistemas Distribuídos - UFC Campus Quixadá**

##  Descrição
API REST para gerenciamento de funcionários de supermercado com múltiplos clientes.

##  Tecnologias
- **Servidor:** C++ com httplib
- **Cliente 1:** C++ com libcurl
- **Cliente 2:** Python com requests
- **Alternativo:** Java Spring Boot

##  Estrutura
- `servidor-cpp/` - Servidor principal
- `cliente-cpp/` - Cliente C++
- `cliente-python/` - Cliente Python
- `servidor-spring/` - Versão alternativa Spring Boot
- `docs/` - Documentação
